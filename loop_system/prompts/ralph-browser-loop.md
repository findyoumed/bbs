# [LOG: 20260428_2312] Ralph Browser Stability Harness for Codex

목표:
- 새 기능 추가보다 기존 기능이 안정적으로 동작하는 상태를 유지/복구하는 데 집중한다.
- `npm run smoke:vercel-ready`와 `npm run smoke:full-traversal`에서 드러나는 실제 오류를 수정한다.
- Playwright가 보고하는 브라우저 콘솔 에러, `pageerror`, 빈 화면, 라우트 회귀를 최우선으로 다룬다.

작업 규칙:
1. `WORK_LOG.md`와 수정 대상 파일을 먼저 읽는다.
2. 루프 메모리 파일 경로가 주어지면 먼저 읽고, 이번 사이클에 끝낸 일과 다음 사이클의 집중 대상을 갱신한다.
3. `smoke:full-traversal` 로그의 `[Browser Error]`, `[Page Error]`, 빈 페이지, 경로 실패를 근거로 정확한 화면과 모듈을 추적한다.
4. 에러를 숨기지 말고 근본 원인을 수정한다. 불필요한 `catch {}` 추가, 로그 제거, 무조건적인 ignore 처리로 통과시키지 않는다.
5. 검증이 모두 통과해도 새 기능을 만들지 말고, 기존 기능 범위 안에서 다음 위험 지점을 하나만 선택해 안정화한다.
6. 요청 범위를 벗어나는 리팩터링, UI 꾸미기, 무관한 기능 추가는 하지 않는다.
7. 수정 후 검증 명령을 다시 실행하고, 어떤 경로에서 어떤 오류를 고쳤는지 `WORK_LOG.md`와 루프 메모리 파일에 기록한다.
8. 최종 보고에는 실행 명령, 기대 결과, 실패 시 확인 사항을 포함한다.
