현재 Git 상태를 분석하고 커밋 전략을 제안합니다.

다음을 순서대로 실행하고 분석하세요:

```bash
git status
git diff --stat
git log --oneline -5
```

분석 후 아래 형식으로 답변하세요:

---

**커밋 전략**
- 이 변경사항이 커밋 1개로 적절한가? (Y/N, 이유)

**add 전략**
- `git add .` 사용이 안전한가? (Y/N)
- 부분 add가 필요한 파일 목록 (있다면)
- 민감한 파일 경고 (`.env`, 비밀키 등)

**주의사항**
- 되돌리기 어려운 변경사항 경고
- 기존 코드 덮어쓴 파일 확인

**커밋 메시지 제안**
```
{type}: {한 줄 설명}

- {변경사항 1}
- {변경사항 2}
```
type 예시: `feat`, `fix`, `refactor`, `style`, `chore`

---

⚠️ **`git push`는 이 도구가 실행하지 않습니다. 사용자가 직접 수동으로 실행하세요.**
