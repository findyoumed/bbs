================================================================================
  1. 프로젝트 개요
================================================================================

  이 프로젝트는 1990년대 PC통신(BBS) 환경을 웹 브라우저에서 재현한
  "웹 터미널 BBS"입니다.

  - 80x24 고정 해상도의 터미널 화면을 기반으로 합니다.
  - 키보드 입력 및 마우스 ANSI 핫스팟 클릭을 모두 지원합니다.
  - v30부터는 모든 소스 코드가 250줄 이하의 전문 모듈로 분리되었습니다.
  - v20260411 표준 명령어 체계를 준수하며, 한글 입력 오타 자동 교정을 지원합니다.

7-1. 기본 명령어 및 입력 정규화
--------------------------------------------------------------------------

v20260429 표준 명령어 체계가 적용되었습니다.

T              초기 화면(메인 메뉴)으로 돌아갑니다.
P 또는 M       이전 화면 또는 상위 메뉴로 돌아갑니다.
L              현재 문맥의 첫 페이지로 돌아가거나 검색을 초기화합니다.
C 또는 H       도움말을 표시합니다.
GO [이름]      특정 서비스로 바로 이동합니다.
WHO [아이디]   사용자 정보를 확인하거나(아이디 입력 시), 접속자 목록을 봅니다(아이디 미입력 시).
USER           현재 접속 중인 사용자 목록을 확인합니다.
COLOR          터미널 배경색 테마를 전환합니다.
X 또는 BYE     BBS를 종료합니다.

[한글 입력 정규화 (Typos)]
한/영 전환을 잊고 한글을 입력해도 자동으로 변환됩니다.
- ㅅ -> T (초기화면)
- ㅣ -> L (목록)
- ㅔ/ㅡ -> P/M (이전)
- ㅊ -> C (도움말)
- 해 -> GO (이동)
- ㄱㄷ -> RE (댓글)
- ㅣㅅ -> LT (제목검색)

  --------------------------------------------------------------------------
  7-2. 게시판 사용법
  --------------------------------------------------------------------------

  게시판 목록 화면의 표준 명령어:

  Enter 또는 F   다음 페이지로 이동합니다.
  B              이전 페이지로 이동합니다.
  L              검색을 해제하고 첫 페이지로 돌아갑니다.
  LT [검색어]    제목+본문으로 검색합니다.
  LI [검색어]    작성자로 검색합니다.
  W              새 게시글을 작성합니다.
  P 또는 M       상위 메뉴로 돌아갑니다.

  --------------------------------------------------------------------------
  7-3. 게시글 읽기/쓰기
  --------------------------------------------------------------------------

  게시글 본문 화면의 표준 명령어:

  Enter          다음 페이지로 스크롤합니다.
  B              이전 페이지로 스크롤합니다.
  A 또는 ]       다음 게시글로 이동합니다. (연속 읽기)
  N 또는 [       이전 게시글로 이동합니다.
  P 또는 M       목록으로 돌아갑니다. (이전 페이지 위치 유지)
  L              게시판의 첫 페이지 목록으로 돌아갑니다.
  OK             현재 게시글을 추천합니다.
  PR             인쇄 화면을 엽니다.

  --------------------------------------------------------------------------
  7-4. 대화방 (채팅)
  --------------------------------------------------------------------------

  대화방 목록:
  O              새 대화방을 개설합니다.
  P 또는 M       상위 메뉴로 이동합니다.

  대화방 내부:
  /Q 또는 /QUIT  대화방을 나가고 목록으로 돌아갑니다. (한글 /ㅂ 지원)
  T              메인 화면으로 즉시 이동합니다.

  --------------------------------------------------------------------------
  7-7. 내 정보 및 프로필 관리
  --------------------------------------------------------------------------

  BIO 또는 HI    내 정보 변경(닉네임, 비밀번호) 및 프로필 정보를 관리합니다.
  WHO [아이디]   회원 정보를 조회합니다.

  --------------------------------------------------------------------------
  7-8. 부가 기능
  --------------------------------------------------------------------------

  ZOOM [IN|OUT|0] 화면 확대/축소 및 초기화
  ALIAS [명령]   나만의 명령어 단축키 생성
  WS [명령]      여러 개의 워크스페이스(가상 화면) 관리
  PERF           시스템 성능 지표 확인
  SYSLOG         시스템 진단 로그 확인
