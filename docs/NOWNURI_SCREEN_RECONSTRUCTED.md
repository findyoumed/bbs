# 💚 나우누리(NOWNURI) 터미널 화면 복원 자료

이 문서는 `nowro` 폴더의 시뮬레이터 데이터(`SIMUL.CAP`, `NOW_MENU.DAT`)를 바탕으로 당시의 BBS 화면을 텍스트로 재구성한 것입니다.

---

## 1. 초기 접속 및 로그인 화면 (Login Screen)

```text
ATDT 01410
CONNECT 19200/ARQ
..................................................................

나 우 누 리 (NOWNURI) 에 오신 것을 환영합니다!
(나우로 v0.9b / baekdu pts/24)

------------------------------------------------------------------
*** '나우', '나우누리', '나우로'는 나우콤이 운영하는 정보서비스입니다. ***
*** 나우누리 ID가 없는 분은 '가입신청' 또는 'GUEST'로 접속하십시오. ***
------------------------------------------------------------------

나우누리 아이디: _
```

---

## 4. 나우누리 전용 단축 명령어 (Shortcuts)

당시 나우누리에서 통용되던 고유 명령어들입니다.

| 명령어 | 기능 | 설명 |
|:---:|:---|:---|
| **tr** | **Transfer** | 자료실(PDS)에서 파일을 다운로드할 때 사용 (전설의 명령어) |
| **go** | **Go** | 특정 서비스로 바로 이동 (예: go humor, go plaza) |
| **say** | **Say** | 대화방에서 특정 상대에게 귓속말 보내기 |
| **who** | **Who** | 현재 접속자 목록 확인 |
| **sos** | **SOS** | 시스템 운영자(시삽)에게 도움 요청 |
| **bye** | **Bye** | 접속 종료 (로그아웃) |

---

> [!TIP]
> **나우로(Nowro)**는 나우누리 전용 접속 프로그램으로, 당시 하이텔의 '이야기'나 '안녕'과 경쟁했던 강력한 한글 에뮬레이터였습니다. 위 화면 구성은 해당 프로그램의 시뮬레이션 데이터를 기반으로 복원되었습니다.
