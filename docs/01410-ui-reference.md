## 공통 화면 구조

- 4:3 비율의 고정형 터미널 화면
- 짙은 네이비/청색 본문 배경과 흰색 고정폭 글꼴
- 상단에 서비스명 또는 화면 제목을 두고 좌우 구분선으로 영역을 나눔
- 제목 오른쪽에 `1/1`, `1/2` 같은 페이지 표시
- 본문은 번호 목록을 고정 열에 배치하며, 한 화면에 2~3개 열을 사용
- 카테고리명은 반전·밝은 배경의 짧은 박스 라벨로 강조
- 하단에는 화면 전환·상위·초기화면·선택 명령을 한 줄 힌트로 표시
- 입력 프롬프트와 커서는 하단 고정 영역에 배치

## 영상에서 확인한 화면 패턴

- `00:00`: 청색 로딩 화면과 중앙 진행 표시
- `00:55`: 서비스 메뉴와 페이지 헤더
- `01:51`: `Web서비스 1/2` 형태의 다열 번호 목록
- `02:46`: 여러 카테고리 박스와 1~100번대 서비스 목록
- `03:42`: 동일한 헤더·구분선을 유지한 빈 결과 안내 화면
- `04:38`: `Password` 메뉴의 번호 선택 화면
- `06:10`: 서비스 안내 본문과 하단 명령 힌트

## 프로젝트 적용 원칙

1. 새 화면도 상단 제목·페이지·구분선의 위치를 기존 터미널 화면과 통일한다.
2. 메뉴 항목은 번호와 텍스트를 고정폭으로 유지하고, 시각적 열 정렬을 우선한다.
3. 본문이 짧아도 하단 명령 힌트와 프롬프트 영역은 유지한다.
4. 마우스 호버·클릭을 추가하더라도 키보드 명령 중심의 화면 밀도와 레트로 시각 체계를 바꾸지 않는다.
5. 색상·간격·페이지 표기는 임의의 현대식 카드 UI보다 원본 터미널 규칙을 우선한다.
