======================================================================
  명령어 통합 목록
======================================================================

  알파벳              한국어           역할
  ──────────────────────────────────────────────────────────
  P, M               상위         상위 메뉴(이전 화면)로 이동
  B                  앞         한 페이지 뒤로 이동
  N, [               이전글           이전 글(번호 낮은 글)로 이동
  A, ]               다음글           다음 글(번호 높은 글)로 이동
  F, Enter           다음            한 페이지 앞으로 이동
  L                  목록             첫 페이지(목록 처음)로 이동
  T                  초기화면           메인 초기 화면으로 이동
  GO [키워드]        이동             해당 서비스로 바로 이동
  W,WRITE            쓰기             새 글 작성
  RE                 댓글             댓글 달기
  E, ED              수정             내 글 수정
  D, DD              삭제             내 글 삭제
  V, OK              추천             글 추천하기
  L, LOGIN           로그인           로그인 실행
  C, COLOR             배경색           배경색 토글 (검정 ↔ 파랑)
  O, OPEN             만들기           새 대화방 만들기
  PR, PRINT           복사            클립보드에 글 내용 복사
  H, help             도움말           도움말 보기
  LT [검색어]        제목검색         제목+본문으로 검색
  LI [아이디]        작성자검색       작성자(아이디/닉네임)로 검색
  PF, WHO [아이디]    사용자         사용자 정보 조회
  ME, XX, TO, EAR, MEMO  쪽지           쪽지 보내기 / 특정 상대에게 메시지

  ── 대화방 내부 명령 (/ 접두사) ──

  /Q, /QUIT          /종료            대화방 퇴장
  /XX, /TO, /EAR, /MEMO  /쪽지           쪽지 보내기 / 특정 상대에게 메시지
  /ST                /대화방            대화방 인원 현황
  /Z                 /다시보기        최근 대화 다시 표시
  /EX [아이디]       /차단            특정 사용자 대화 차단
  /OUT [아이디]      /내보내기            특정 사용자 강제 퇴장
  /JUDGE             /신고            사용자 신고
