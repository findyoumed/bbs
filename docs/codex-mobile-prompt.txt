이 프로젝트는 90년대 PC통신 BBS를 웹으로 재현한 바닐라 JS 앱입니다.
현재 데스크톱(800px 고정 폭)에서만 작동하며, 모바일(세로형, 320px~480px)에서는 가로 스크롤이 발생하고 글자가 잘립니다.

### 작업 목표
모바일 세로형 화면(max-width: 768px)에서 사용할 수 있도록 CSS 반응형을 추가합니다.

### 수정 대상 파일
`public/style.css` 파일 끝에 `@media` 블록을 추가합니다.
기존 CSS를 수정하지 마세요. 파일 맨 끝에 미디어 쿼리를 추가만 하세요.

### 반드시 지켜야 할 규칙

1. **기존 코드 보존**: `public/style.css`의 기존 내용을 절대 수정/삭제하지 마세요.  
   파일 맨 끝에 `/* 모바일 반응형 */` 주석과 함께 `@media` 블록만 추가하세요.

2. **JS 파일 수정 최소화**: 아래 "9. 모바일 키보드 방지" 항목에 해당하는 부분만 수정하세요. 그 외 JS는 건드리지 마세요.

3. **HTML 수정 금지**: `public/index.html`은 건드리지 마세요.  
   단, `<meta name="viewport">` 태그가 없다면 `<head>` 안에 추가하세요.

4. **프레임워크 금지**: Tailwind, SCSS 등 사용하지 마세요. 바닐라 CSS만 사용하세요.

### 구체적으로 해야 할 것

`@media (max-width: 768px)` 블록 안에서 다음을 처리하세요:

#### 1. 전체 레이아웃
- `body`: padding을 `8px 4px 16px`으로 줄이기
- `.app-shell`: `width: 100%`, `min-height: 100vh`
- `#terminal-wrapper`: `max-width: 100%`, `height: auto`, `min-height: calc(100vh - 32px)`
- `#terminal-container`: `min-height: calc(100vh - 32px)`, `height: auto`
- `#terminal-screen`: `overflow-y: auto`, `overflow-x: hidden`, `-webkit-overflow-scrolling: touch`

#### 2. 폰트 크기 축소
- `#terminal-container`, `.ansi-screen`, `.ansi-line`: `font-size: 12px`
- `body`: `font-size: 14px`
- `.retro-topbar--ansi`: `font-size: 12px`

#### 3. ANSI 화면 가로 스크롤 방지
- `.ansi-screen`: `max-width: 100%`, `overflow-x: auto`
- `.ansi-screen-body`: `max-width: 100%`, `padding: 0 4px`
- `.ansi-line`: `font-size: 12px` (80컬럼 x 12px = 약 480px에 맞춤)

#### 4. 상단 헤더 (topbar) 축소
- `.retro-topbar--ansi .retro-topbar-row1`: `padding: 0 4px`
- `.retro-topbar--ansi .retro-topbar-row2`: `padding: 0 4px`
- `.retro-topbar--ansi .retro-topbar-left`: `padding: 1px 4px`, `font-size: 11px`
- `.retro-topbar--ansi .retro-topbar-clock`: `font-size: 11px`

#### 5. 하단 입력 영역
- `#terminal-footer`: `padding: 2px 4px 1px`, `min-height: 32px`
- `#cmd-input`: `font-size: 14px` (터치 키보드 줌 방지를 위해 최소 16px 고려)

#### 6. 게시판 목록
- `.post-table`: 가로 스크롤 허용 또는 컬럼 숨기기
- `.post-row .date`, `.post-row .num`: `display: none` (좁은 화면에서 숨김)

#### 7. 글쓰기 폼
- `.write-field input`, `.write-field textarea`: `font-size: 16px` (iOS 줌 방지)

#### 8. 더 좁은 화면 (max-width: 400px)
- `.ansi-line`, `.ansi-screen`, `#terminal-container`: `font-size: 10px`
- `.retro-topbar--ansi .retro-topbar-clock`: `display: none` (시계 숨김)

#### 9. 모바일 키보드 방지 (JS 수정)
모바일에서 페이지 로드 시 가상 키보드가 자동으로 올라오면 안 됩니다.

**수정 파일**: `public/js/core/appEvents.js`

현재 이 파일 하단에 `cmdInput.focus()`를 호출하는 부분이 있습니다.
`#terminal-wrapper` 클릭 시 `cmdInput.focus()`를 호출하는 코드 블록에 이미 아래 조건이 있습니다:

```javascript
if (window.matchMedia('(hover: hover) and (pointer: fine)').matches) {
```

이 조건 덕분에 터치 기기에서는 wrapper 클릭 시 focus가 가지 않습니다. 이 부분은 수정하지 마세요.

**추가 수정 파일**: `public/js/core/menuNavigation.js`

`showMain` 함수와 `showBoardSelect` 함수 끝에 `cmdInput.focus();`가 있습니다.
이 두 곳의 `cmdInput.focus();`를 아래처럼 변경하세요:

```javascript
// 모바일에서 키보드 자동 팝업 방지
if (window.matchMedia('(hover: hover) and (pointer: fine)').matches) {
  cmdInput.focus();
}
```

**같은 패턴으로 수정할 파일 목록** (각 파일에서 `cmdInput.focus()` 검색 후 동일하게 감싸기):
- `public/js/core/menuNavigation.js` (2곳)
- `public/js/core/postListView.js` (`showPostList` 함수 끝)
- `public/js/core/postViewView.js` (`showPostView` 함수 끝)
- `public/js/core/chatScreens.js` (채팅방 진입 후)

**주의**: 로그인/글쓰기 폼처럼 사용자가 직접 입력해야 하는 화면의 focus()는 건드리지 마세요.
