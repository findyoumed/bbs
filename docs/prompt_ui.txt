 작업을 계속 진행해라. 사용자는 멈추지 말고 반복해서 계속 진행하기를 원한다.

  - 이유:
    - `www-nodejs`는 이미 다른 작업(EZBBS 이식, 01410 UI 오버레이 등)이 많이 섞여 있음
    - `olddos-bbs-main` 재구현은 별도 프로젝트로 관리하는 게 맞음

  - 즉:
    - telnet/terminal 프로그램을
    - 웹 구조로 다시 설계하고
    - 점진적으로 구현하는 것이다.

  [현재 알고 있는 사실]
  1. `olddos-bbs-main`은 웹서버가 아니라 텔넷 BBS다
  - INSTALL.TXT에 `xinetd`, `telnet-server`, `in.telnetd`, `runbbs`가 나옴
  - `runbbs`가 실제 진입점 역할
  - `src/main.cpp`가 메인 루프 성격
  - `txt/*.txt`, `.mnu` 파일로 메뉴/화면 구성
  - `src/chattserver.cpp` 등은 별도 소켓 채팅 서버 성격

  2. README에 `https://bbsweb.oscc.kr/`가 나오지만
  - 저장소 자체는 웹 앱이 아니라 터미널 BBS 엔진
  - 웹 접속은 별도 웹 터미널 브리지일 가능성이 큼

  3. 따라서 이번 일은
  - “웹텔넷 붙이기”가 아니라
  - “기능을 웹 구조로 재구현”하는 일이다
