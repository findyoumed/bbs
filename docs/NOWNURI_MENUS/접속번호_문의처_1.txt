< 대화방명령어 >                                                          1/1
 대화실에는 전체 서비스와는 다른 별도의 명령어가 몇가지 있습니다.

 명령어는 대기실에서 쓰는것과 대화실에서 쓰는 것으로 나뉘는데 대화
 실에서는 대화내용과의 구분을 위하여 모든 명령어 앞에 '/'를 입력해
 야 합니다.

## 대기실 명령어 ##

  J 방번호    : 대화 참여
  O           : 대화실 열기
  WH id       : 특정이용자 이용현황 보기
  FI id       : 특정이용자 대화실 이용현황 보기
  LT title    : 입력된 단어가 포함된 제목으로 대화방 찾기
  USER        : 현 서비스 이용자 이용현황 보기
  PF id       : 이용자 프로필 (서비스안내에서 입력/수정)
  AL 대화명   : 대화도중 자신의 대화명 변경
  ST          : 대화실 전체 이용 현황 (ST 방번호, ST TITLE 가능)
  ST OP,ST CLO: 공개방 현황보기, 비공개방 현황보기

## 대화실 명령어 ##

  /WH id        : 특정이용자 이용현황 보기
  /FI id        : 대화실내 특정이용자 찾기
  /LT title     : 입력된 단어가 포함된 제목으로 대화방 찾기
  /UID          : 전체 접속자 이용자번호(ID) 목록 보기
  /USER         : 현 서비스 이용자 이용현황 보기
  /PF id        : 이용자 프로필 (서비스안내에서 입력/수정)
  /IN ID        : 특정이용자 초대 (비공개의경  비밀번호 통보)
  /ST           : 참여 대화실 현황 (/ST 방번호, /ST ALL도 가능)
  /ST TITLE     : 대화방 제목보기
  /ST OP,/ST CLO: 공개방 현황보기, 비공개방 현황보기
  /AL 대화명    : 대화도중 자신의 대화명 바꾸기
  /E TITLE 주제 : 대화실 주제 바꾸기 (개설자만 가능)
  /E USER 인원  : 대화실 참여제한인원 바꾸기 (개설자만 가능)
  /EX id        : 특정이용자 대화내용 수신거부
  /OUT id       : 특정이용자 퇴장시키기
  /JUDGE        : 대화내용 운영진에 고발하기
  /Z,/Z 숫자    : 지나간 대화내용 다시보기
  /P,/T,/GO     : 대화종료(이동명령)
  /BYE,/QUIT    : 접속종료,(/X는 대화실에서 이용불가)
