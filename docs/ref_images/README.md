# PC통신 참고 이미지 인벤토리

이 폴더는 서비스 UI와 명령어 화면을 비교하기 위한 참고 이미지 보관소다. 실제 서비스 화면 자산으로 자동 사용하지 않는다.

## 감사 기준

- 이미지 형식: PNG, JPEG, GIF, WebP
- 초소형 제외 기준: 가로 160px 미만 또는 세로 100px 미만
- 중복 기준: 파일 SHA-256이 같거나, 같은 화면을 단순히 축소·재인코딩한 명확한 시각 중복
- 2026-08-29 감사 결과: 15개 파일, 초소형 0개, 폴더 내·`docs/종료공지`와의 중복 0개

직접 원본 URL이 보존되지 않은 기존 수집본은 출처를 추측하지 않고 `미기록(기존 수집본)`으로 표시한다. 검색 결과 URL은 원본 파일 URL이 아니므로 원본 링크로 간주하지 않는다.
