0. 나우누리 UI 문법 요약 (캡처+복원 화면 실측)
--------------------------------------------------------------------------------
- 배경: 파랑(#0000AA 계열) + 흰 글자, 강조는 노랑. 상태바는 청록/노랑.
- 헤더 1줄: `GO코드          가운데 화면제목          ☎ 02-590-3800` (우측은
  문서형 화면에서 `1/28` 쪽번호로 대체).
- 메뉴: 다단 배치 + `[ 섹션명 ]` 그룹 라벨 + 항목별 `( 신규 / 전체 )` 건수.
- 게시판 목록 컬럼: `번호 올린ID 이름 날짜 읽음 쪽 제목` — ID와 **실명 병기**.
- 푸터: `명령어안내(C) 초기메뉴(T) 직접이동(GO) 종료(X)` + `선택>` 프롬프트.
- 대화실(CHATIN): 대기실 명단 + `[방번호] 공개(현재/정원) 방제목` + 참여자
  `별명(실명)` 나열.
- 전자우편: 편지읽기(RMAIL)/쓰기(WMAIL)/배달 확인·취소(CMAIL) 3분할.

1. 이미 우리에게 있는 것 (변경 불필요)
--------------------------------------------------------------------------------
- 여론광장(ACRO) 상당 기능 = Vote 모듈 존재.
- GO 직행/T 초기화면/X 종료 명령 체계 동일 (하이텔과 나우누리가 원래 유사).
- 메인 2열 배치(U-1 완료)는 나우누리 TOP 다단 문법과도 정합.

■ N-11. GUIDE 화면 "12.이용약관" 정적 문서 뷰어  [✅ 완료 20260713_2100]

■ N-10. GUIDE 화면 "[이용안내]" 바로가기 인덱스 재현  [❌ 20260713_2030에 추가했다가
   20260713_2300에 사용자 지적으로 되돌림 — 자료실/개인영역/전자우편/대화실/온라인
   오락실 바로가기는 나우누리 원전(TOP 3단 배치라 요약 인덱스가 유의미)과 달리, 이
   앱은 TOP이 1열 전체 노출 구조라 TOP 3/4/6/8/9번과 완전히 동일한 화면으로 가는
   순수 중복이었다. 원전을 맥락 고려 없이 기계적으로 베낀 실수 — 재제안 금지.
   type="shortcut" 메커니즘(menuNavigationActions.js)도 사용처가 없어져 함께 제거.
   명령어안내(type=help)/이용약관·개인정보처리방침(type=policy)만 유지 — 이 셋은
   TOP에 없는 진짜 신규 기능이라 GUIDE에 남기는 게 타당함.
