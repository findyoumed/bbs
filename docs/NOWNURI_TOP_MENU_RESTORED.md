> [!IMPORTANT]
> **왜 깨져 보였나요?**
> 당시 나우누리는 초성, 중성, 종성을 각각 조합하여 글자를 만드는 **조합형(KS X 1001:1992 Appendix 4)** 방식을 사용했습니다. 현재 대부분의 텍스트 에디터는 **완성형(CP949)** 혹은 **UTF-8**만 지원하기 때문에, 조합형 데이터를 그대로 열면 깨진 코드로 나타납니다. 
> 
> 위 내용은 제가 `johab` 코덱을 사용하여 해당 바이너리 값을 실제 글자로 하나하나 매핑하여 복원한 것입니다.
