================================================================================
   1. 프로젝트 개요 및 아키텍처
================================================================================

  전통적인 텍스트 기반 BBS 호스트 서버를 Windows 환경에서 구현한 프로젝트입니다.
  Delphi(Object Pascal) 언어로 작성되었으며, 멀티 스레드 모델을 채택하고 있습니다.

  [ 내부 아키텍처 소스 구성 ]
  - EZBBS.dpr   : 프로젝트 메인 엔트리 포인트. 애플리케이션 초기화 및 실행.
  - MainUnit.pas: 메인 윈도우 폼. 설정 로드 및 전체 시스템 인덱스 관리.
  - Client.pas  : 사용자 세션(Thread) 처리 로직. 명령어 해석 및 기능 수행의 핵심.
  - Socket.pas  : 텔넷 소켓 수신 및 Accept 처리. 이벤트를 Client 유닛으로 전달.
  - httpcont.pas: 간이 HTTP 서버 로직. 80 포트를 통한 웹 브라우저 지원.
  - Log.pas     : 서버 내의 모든 접속/이동 기록을 로그 파일로 기록.
  - Declare.pas : 전역 상수(Const), 색상 코드, 메뉴 타입(K_Board 등) 정의.
  - Envior.pas/Sockset.pas: 설정 관리를 위한 GUI 폼 소스.

  [ 동작 원리 ]
  - MAIN WINDOW: 소켓 메시지 윈도우를 통해 접속 요청을 수신합니다.
  - USER THREAD: 각 접속자마다 독립적인 스레드가 할당되어 게시판, 채팅, 메일 등의 기능을 수행합니다.

   2. 사전 준비 사항
================================================================================

  2-1. 하드웨어/OS 환경
    - Windows 9x/ME/NT/2000/XP 및 최신 Windows 환경 지원.
    - 최소 64MB 이상의 램 권장 (동시 접속자 100명 기준).

  2-2. 네트워크 설정
    - 텔넷 표준 포트: 23번 (설정에서 변경 가능)
    - 외부 서비스 시: 공유기 설정에서 23번 포트의 포트 포워딩 필수.


================================================================================
   3. 설치 및 서버 실행
================================================================================

  3-1. 실행 파일 구성 (Root 디렉토리)
    - EZBBS.EXE     : BBS 서버 실행 엔진.
    - USEREDITOR.EXE: 회원 정보 수정/삭제용 보조 도구.
    - MENUEDITOR.EXE: 게시판 트리 및 메뉴 구성 관리 도구.

  3-2. 서버 기동
    1. EXBBS.EXE를 실행합니다. 
    2. 하단 상태 바에 "현재 포트 23 대기 중" 또는 "서버 가동 중" 메시지를 확인합니다.
    3. 접속 시 "EASY BBS" 환영 로고가 나타나면 성공입니다.


================================================================================
   4. 서버 환경 설정 (GUI 및 설정 파일 명세)
================================================================================

  서버 루트 폴더의 설정 파일(.cfg)들은 텍스트 에디터로 수정 가능하지만,
  가급적으로 서버 프로그램 내의 GUI 메뉴를 이용하십시오.

  4-1. 주요 설정 파일 명세 (CFG 형식)
    - port.cfg      : [TelnetPort], [HTTPPort] 두 줄로 구성.
    - bbsname.cfg   : BBS의 공식 명칭 (최상단 타이틀에 표시).
    - logonmsg.cfg  : 접속 시 ID를 묻기 전에 보여줄 환영 문구.
    - etc.cfg       : 3줄 (Y/N/Y 등의 Flag)
                      1줄: RunBind 여부 (Y/N)
                      2줄: 시스템 트레이 시작 여부 (RunHide, Y/N)
                      3줄: 중복 로그인 허용 여부 (MultiLogin, Y/N)
    - emotions.cfg  : 채팅방 감정 표현 정의.

  4-2. 감정 표현 설정 (emotions.cfg) 형식
    이 파일은 "명령어"와 "출력 문구"가 한 쌍으로 반복됩니다.
    예시:
    ---
    웃음
    방긋 미소를 짓습니다.
    샘플
    %s유저에게 샘플 이모티콘을 던집니다.
    ---
    - %s 기호는 대상 사용자의 대화명(닉네임)으로 대치됩니다.


================================================================================
   5. 프로젝트 디렉토리 및 데이터 구조 (상세)
================================================================================

  5-1. 메뉴(Menu) 트리 구조
    메뉴는 실제 폴더 구조를 따라갑니다. (기본 트리: d:\EZBBS\MENU\...)
    예: MENU\1\1\1 (1번 메뉴의 1번 서브메뉴의 1번 메뉴)

  5-2. MENU.DAT 상세 명세
    각 메뉴 폴더 내에 반드시 존재해야 하는 파일입니다 (3줄 형식).
    1줄: 메뉴 종류(Kind) 코드 (숫자)
         0 : 상위 메뉴 (하위 폴더/메뉴들을 가짐)
         1 : 일반 게시판 (글쓰기/읽기/삭제)
         2 : 대화방 (채팅방 로비)
         3 : 우편함 수신 (Read Mail)
         4 : 우편함 송신 (Write Mail)
         5 : 개인 정보 수정 (EditMyData)
         6 : 공지 게시판 (관리자만 쓰기 가능)
         7 : 숨겨진 메뉴
    2줄: 메뉴 인덱스 (내부 식별용 문자열)
    3줄: 화면에 표시될 메뉴 이름 (ex: 자유게시판)

  5-3. 게시글 데이터 포맷 (Board)
    게시판 폴더 내에는 1.txt, 2.txt... 파일들이 생성됩니다.
    [파일 상단 헤더 구조 (8줄)]
    1: 접근 권한 정보 (삭제된 경우 '*' 표시, 정상일 경우 ' ')
    2: 제목
    3: 올린이 아이디
    4: 올린이 이름(닉네임)
    5: 작성 날짜 (YYYY/MM/DD)
    6: 작성 시각 (HH:MM:SS)
    7: 조회수 (Hit count)
    8: 전체 페이지 수
    (9줄부터 : 실제 게시글 본문 텍스트 데이터)

  5-4. 사용자(User) 및 메일(Mail) 데이터 상세
    - userdata\{ID}.dat : 회원 상세 프로필 (성명, 주소, 비번 등).
    - userdata\{ID}.id  : 해당 계정의 가입 여부 확인용 (0바이트 파일).
    - mail\{ID}.mem     : 미확인 실시간 쪽지(Memo) 보관 텍스트.
    - mail\{ID}.{번호}   : 수신된 각 편지 파일 (1, 2, 3...). 
                          첫 줄이 '*'이면 삭제된 편지입니다.


================================================================================
   6. 터미널(Telnet) 사용법 (일반 사용자)
================================================================================

  6-1. 기본 터미널 명령어 및 단축키
    - C (명령어 안내) : 현재 위치에서 사용 가능한 명령어 도움말.
    - T (초기 화면)   : 최상위 메인 메뉴로 즉시 복귀.
    - P (상위 메뉴)   : 한 단계 위 메뉴(폴더)로 이동.
    - GO [코드]       : 지정한 ChoiceIndex(메뉴 단축 코드)로 점프.
    - X / BYE         : 접속 종료 (로그아웃).
    - USER            : 현재 접속 중인 전체 유저 목록 확인.
    - TO [ID]         : 실시간 메시지 전송 (상대방 화면 하단에 즉시 표시).
    - MEMO [ID] [내용]: 부재 중이거나 접속 중인 유저에게 쪽지 남기기.

  6-2. 회원 가입 및 로그인 (GUEST 접속)
    - 손님 접속: ID 입력 시 "손님" 또는 "guest" 입력.
    - 가입 절차: 이름(실명) -> 아이디 선정 -> 패스워드 설정 -> 생년월일 입력.
    - 가입 후 즉시 해당 정식 아이디로 로그인 처리됩니다.

  6-3. 게시판 상세 명령어 (Board)
    - [번호] 입력 : 해당 번호 글 읽기.
    - 엔터 / N    : 다음 목록 페이지 이동.
    - B           : 이전 목록 페이지 이동.
    - W           : 글쓰기. 본문 끝에 마침표(.)만 찍고 엔터를 누르면 저장.
    - D [번호]    : 글 삭제 (자신의 글 혹은 관리자 전용).
    - 읽기 모드 중:
      A (다음 글로 연속 읽기), N (이전 글로 연속 읽기).

  6-4. 대화방(채팅) 및 감정 표현
    - C : 새 대화방 개설 (공개/비밀 설정 가능).
    - [번호] : 대화방 입장.
    - /q : 대화방 퇴장.
    - /z : 최근 20줄 대화 히스토리 다시 불러오기.
    - /w [ID] : 특정인에게 귓속말 전송.
    - /[감정어] : emotions.cfg에 등록된 액션 메시지 수행.

  6-5. 우편함 및 쪽지
    - 쪽지(TO) 수신 시 화면 하단에 ID와 메시지가 고정 표시됩니다.
    - 편지함 진입 시 안 읽은 편지에 'R' 표시가 나타납니다.


================================================================================
   7. 관리자 도구 (MenuEditor, UserEditor)
================================================================================

  7-1. MENUEDITOR.EXE (메뉴 에디터)
    - 실제 MENU 폴더 구조와 매칭되는 트리 뷰를 제공합니다.
    - 각 폴더의 "admin.cfg"를 수정하여 게시판 관리자를 지정할 수 있습니다.
    - "menu.txt"(메뉴 화면), "premenu.txt"(진입 시 안내) 파일을 관리합니다.

  7-2. USEREDITOR.EXE (사용자 에디터)
    - userdata 폴더를 스캔하여 가입된 회원 정보를 그리드로 보여줍니다.
    - 아이디 중복 제거, 패스워드 수동 변경, 탈퇴 처리가 가능합니다.


================================================================================
   8. 소스 코드 구성 및 내부 로직 설명 (기술 가이드)
================================================================================

  - 폰트/인코딩: ANSI(EUC-KR/CP949) 기반 렌더링.
  - ANSI 이스케이프: 화면 이동(ESC [y;xH), 반전(ESC [7m), 클리어(ESC [2J) 등 사용.
  - 동기화 메커니즘: CriticalSection을 통해 동시 접속자의 파일 IO 충돌을 방지합니다.
  - TUser 클래스(Client.pas): Execute 메서드 내에서 무한 루프로 상태(State)별 입력을 처리합니다.


================================================================================
   9. 멀티미디어 및 웹 리소스 명세 (VOICE, WEB)
================================================================================

  EZBBS는 서버 측 알림음과 기본적인 웹 페이지 리소스를 포함하고 있습니다.

  9-1. 서버 알림음 (VOICE.RC 리소스)
    서버 실행 중 특정 이벤트 발생 시 서버 컴퓨터에서 재생되는 음향 효과입니다.
    - START      : 서버 엔진 기동 시
    - SOCKINIT   : 소켓 서비스 초기화 완료
    - CONNECT    : 새로운 사용자가 텔넷으로 접속 시
    - DISCON     : 사용자가 접속을 종료하거나 끊겼을 때
    - LOADING    : 데이터 로딩 중
    - ERROR      : 시스템 오류 또는 포트 바인딩 실패 시
    - APPLY/CANCEL: 설정 적용 또는 취소 시

  9-2. 웹 리소스 (WEB.RC 리소스)
    HTTP 포트(80)를 통해 접속할 때 사용되는 HTML 템플릿입니다.
    - TPLOGO.HTM : 웹 메인 로고 화면
    - TPINPUT.HTM: 아이디/비밀번호 입력 폼
    - TPGUEST.HTM: 웹 전용 게스트 안내 페이지
    - LOGO1.JPG / LOGO2.JPG: 웹 페이지용 로고 이미지


================================================================================
  10. 문제 해결 및 팁 (트러블슈팅)
================================================================================

  - 포트 충돌: "Failed: Binding" 에러가 나면 23번 혹은 80번 포트가 이미 점유된 것입니다.
  - 한글 입력: 한글 입력 모드에서 명령어가 안 먹힐 경우 영어 모드로 전환하십시오.
  - 관리자 권한 상실: MENU\폴더\admin.cfg 파일을 메모장으로 열어 본인 아이디만 적고 저장하십시오.
  - 시스템 트레이: RunHide=Y 설정 시 프로그램 아이콘이 눈에 띄지 않으니 트레이 영역을 확인하십시오.
