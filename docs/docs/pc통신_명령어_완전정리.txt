======================================================================
  하이텔 / 나우누리 / 천리안  PC통신 명령어 완전 정리
  기능별 3사 비교 + 통신사별 전체 목록
======================================================================


======================================================================
  01. 접속 및 로그인
======================================================================

모뎀으로 통신사 서버에 전화를 걸어 접속한 뒤 아이디와 암호를 입력합니다.
하이텔과 나우누리는 같은 망(01410)을 공유했고,
천리안은 독자 망(01420)을 별도로 사용했습니다.

접속 전화번호
  하이텔   ATDT 01410
  나우누리  ATDT 01410  (하이텔 망 공유, 접속 후 나우누리 선택)
  천리안   ATDT 01420  (천리안 전용 독자 번호)

접속 후 프롬프트 모양
  하이텔   [HiTEL] Command:        (영어 Command)
  나우누리  [나우누리] 명령어:         (한글 프롬프트 - 최초)
  천리안   [천리안] >>              (>> 기호 스타일)

팁: 프롬프트 생김새만 봐도 어느 통신사인지 바로 알 수 있었습니다.
    나우누리는 한글 프롬프트를 쓴 최초의 PC통신 서비스였습니다.


======================================================================
  02. 이동 명령어
======================================================================

----------------------------------------------------------------------
  go [키워드]   --   3사 공통 (키워드는 통신사마다 일부 다름)
----------------------------------------------------------------------

어느 화면에서든 go 뒤에 키워드를 치면 해당 서비스로 바로 이동합니다.
PC통신에서 가장 핵심적인 명령어입니다.

3사 공통으로 동일한 go 키워드
  go humor       유머란
  go chat        대화방(채팅)
  go mail        전자우편
  go bluehouse   청와대 신문고

하이텔 주요 go 키워드
  go plaza       자유/시사 게시판 (하이텔의 대표 게시판)
  go humor       유머란
  go pgf         PC게임 동호회
  go anc         애니메이션 동호회
  go jubu        주부 동호회
  go barun       바른통신 동호회
  go summer      여름 이벤트 서비스
  go bluehouse   청와대 신문고
  go chat        대화방
  go mail        전자우편

나우누리 주요 go 키워드
  go plaza       자유/시사 게시판
  go humor       유머란
  go elf         에뮬레이터 동호회 (나우누리 최초 단독 go 키워드 부여)
  go gmf         PC게임 동호회
  go vg          콘솔게임 동호회
  go sf          SF·소설 게시판
  go anc         애니메이션 동호회
  go bluehouse   청와대 신문고
  go chat        대화방
  go mail        전자우편

  나우누리 특이사항: 우리말 키워드도 지원했습니다.
  예) go 유머란  이라고 쳐도 들어갈 수 있었습니다.
  go elf는 나우누리 역사상 최초로 단독 go 키워드를 부여받은 동호회로,
  원래는 go pgf 55 처럼 번호까지 쳐야 들어갈 수 있었습니다.

천리안 주요 go 키워드
  go word        시사/자유 게시판 (하이텔의 go plaza에 해당)
  go humor       유머란
  go cholcd      천리안 CD 신청 서비스
  go bluehouse   청와대 신문고
  go chat        대화방
  go mail        전자우편

  천리안의 시사/자유 게시판 키워드는 go plaza가 아니라 go word입니다.

----------------------------------------------------------------------
  p   또는   prev   --   3사 공통
----------------------------------------------------------------------

현재 화면에서 상위 메뉴(이전 화면)로 돌아갑니다.
브라우저의 뒤로가기 버튼과 같은 역할.

  사용 예)
  [프라자] Command: p         <- 하이텔
  [유머란] 명령어: p          <- 나우누리
  [word] >> p                 <- 천리안

----------------------------------------------------------------------
  m   또는   main   --   3사 공통
----------------------------------------------------------------------

어느 화면에서든 메인(첫 화면)으로 한 번에 이동합니다.

  사용 예)
  [자료실] 명령어: m

----------------------------------------------------------------------
  q   또는   quit   --   3사 공통
----------------------------------------------------------------------

현재 서비스를 종료합니다. 로그인 화면에서 치면 접속을 끊습니다.

  사용 예)
  [천리안] >> q

----------------------------------------------------------------------
  bye   또는   logout   --   3사 공통
----------------------------------------------------------------------

통신사 서버에서 완전히 로그아웃하고 모뎀 연결을 끊습니다.
분당 요금이 부과되던 시대라 bye를 치는 순간이 매우 중요했습니다.

  사용 예)
  [HiTEL] Command: bye
  안녕히 가십시오. 또 오세요.

  팁: 당시에는 분당 요금이 부과됐습니다. 읽을 글을 메모장에 미리
  복사해 두고 최대한 빨리 bye를 치는 것이 생활 요령이었습니다.

----------------------------------------------------------------------
  숫자 입력 (1, 2, 3...)   --   3사 공통
----------------------------------------------------------------------

메인 메뉴나 서비스 목록 화면에서 번호를 직접 입력해 항목을 선택합니다.

  사용 예)
  [HiTEL] Command: 1        <- 1번 메뉴 선택


======================================================================
  03. 게시판 - 목록 보기
======================================================================

----------------------------------------------------------------------
  l   또는   list   --   3사 공통
----------------------------------------------------------------------

게시판의 글 목록을 화면에 출력합니다.
번호를 함께 쓰면 그 번호부터 목록을 보여줍니다.

  사용 예)
  [프라자] Command: l          <- 최신 글 목록
  [프라자] Command: l 500      <- 500번부터 목록
  [유머란] 명령어: l 50        <- 50번부터 목록
  [word] >> list               <- 천리안, list도 가능


======================================================================
  04. 게시판 - 글 읽기 / 이전,다음 이동 / 번호 이동 / 새글만 보기
======================================================================

----------------------------------------------------------------------
  r [번호]   또는   read [번호]   --   3사 공통
----------------------------------------------------------------------

지정한 번호의 글을 읽습니다.
번호 없이 r만 치면 현재 위치의 다음 글로 이동합니다.

  사용 예)
  [프라자] Command: r 1024
  [유머란] 명령어: r 5432
  [word] >> r 888
  [word] >> read 888           <- 천리안은 긴 형태도 가능

----------------------------------------------------------------------
  n   또는   next   --   3사 공통
----------------------------------------------------------------------

다음 번호 글로 이동합니다. 글을 읽는 도중이나 읽은 후에 씁니다.

  사용 예)
  [글 읽는 중] Command: n

----------------------------------------------------------------------
  b   또는   back   --   3사 공통
----------------------------------------------------------------------

이전 번호 글로 돌아갑니다.

  사용 예)
  [글 읽는 중] 명령어: b

----------------------------------------------------------------------
  f [번호]   --   3사 공통
----------------------------------------------------------------------

특정 번호 글 위치로 바로 이동합니다.
오래된 글을 빠르게 찾아갈 때 사용했습니다.

  사용 예)
  [프라자] Command: f 2000     <- 2000번 글 위치로 바로 이동

----------------------------------------------------------------------
  new   또는   nw   --   3사 공통
----------------------------------------------------------------------

지난번 접속 이후 새로 올라온 글만 골라서 보여줍니다.
자주 방문하는 게시판에서 새 글만 빠르게 확인할 때 사용했습니다.

  사용 예)
  [word] >> new
  [유머란] 명령어: new


======================================================================
  05. 게시판 - 글 쓰기 / 답글 / 수정 / 삭제 / 도움말
======================================================================

----------------------------------------------------------------------
  w   또는   write   --   3사 공통
----------------------------------------------------------------------

새 글을 작성합니다.
제목과 내용을 입력한 후 Ctrl+Z(또는 /end)로 저장합니다.
Ctrl+C를 누르면 작성을 취소합니다.

  사용 예)
  [프라자] Command: w

  제목: 오늘 있었던 웃긴 일
  내용 입력 (Ctrl+Z 로 저장, Ctrl+C 로 취소):
  오늘 버스에서 정말 황당한 일이...
  ^Z
  글이 저장되었습니다. (1025번)

----------------------------------------------------------------------
  re [번호]   또는   a [번호]   또는   answer [번호]   --   3사 공통
----------------------------------------------------------------------

특정 글에 답글(리플)을 답니다.
re, a, answer 세 가지 형태 모두 사용 가능했습니다.

  사용 예)
  [유머란] 명령어: re 5432     <- 5432번 글에 답글
  [word] >> re 888             <- 천리안도 re 동일

----------------------------------------------------------------------
  e [번호]   또는   edit [번호]   --   3사 공통
----------------------------------------------------------------------

자신이 작성한 글을 수정합니다.
다른 사람의 글은 수정할 수 없습니다.

  사용 예)
  [프라자] Command: e 1024     <- 본인 글만 가능

----------------------------------------------------------------------
  d [번호]   또는   delete [번호]   --   3사 공통
----------------------------------------------------------------------

자신이 작성한 글을 삭제합니다.
삭제 전 확인 메시지가 표시됩니다.

  사용 예)
  [유머란] 명령어: d 5432
  삭제하시겠습니까? (y/n): y
  글이 삭제되었습니다.

----------------------------------------------------------------------
  h   또는   help   --   3사 공통
----------------------------------------------------------------------

현재 화면에서 사용 가능한 명령어 목록과 도움말을 출력합니다.

  사용 예)
  [word] >> help


======================================================================
  06. 게시판 - 검색   [3사 명령어 다름!]
======================================================================

제목 검색과 내용 검색 명령어가 하이텔.나우누리와 천리안이 다릅니다.

----------------------------------------------------------------------
  제목 검색
----------------------------------------------------------------------

  하이텔   gl [검색어]
  나우누리  gl [검색어]        <- 하이텔과 동일
  천리안   subj [검색어]      <- 전혀 다른 명령어

  gl 은 get list의 약자입니다.
  천리안의 subj는 subject(제목)의 약자입니다.

  사용 예)
  [프라자] Command: gl 대통령
  [유머란] 명령어: gl 군대
  [word] >> subj 선거

----------------------------------------------------------------------
  내용(본문) 검색
----------------------------------------------------------------------

  하이텔   ga [검색어]
  나우누리  ga [검색어]        <- 하이텔과 동일
  천리안   body [검색어]      <- 전혀 다른 명령어

  제목 검색보다 시간이 더 걸렸습니다.

  사용 예)
  [프라자] Command: ga 대통령
  [유머란] 명령어: ga 군대
  [word] >> body 선거


======================================================================
  07. 자료실 - 파일 다운로드 / 업로드 / 목록 / 검색   [일부 3사 다름!]
======================================================================

파일 다운로드 명령어가 3사 모두 다릅니다.
특히 나우누리의 tr은 전설적인 명령어였습니다.

----------------------------------------------------------------------
  파일 다운로드   [3사 명령어 다름!]
----------------------------------------------------------------------

  하이텔   dl [번호]   또는   download [번호]
  나우누리  tr [번호]                           <- 전설의 명령어
  천리안   get [번호]

  나우누리의 tr(transfer)은 속도와 안정성으로 유명해졌고,
  이 명령어 하나 때문에 하이텔.천리안 유저들이 나우누리로
  대거 이동하는 일이 있었습니다.
  당시 전송 방식으로 Zmodem, Xmodem, Ymodem 중 선택할 수 있었으며
  Zmodem이 가장 빠르고 안정적이었습니다.
  Zmodem은 전송 도중 끊겨도 이어받기가 가능했습니다.

  사용 예)
  [자료실] Command: dl 1234                    <- 하이텔

  [자료실] 명령어: tr 1234                     <- 나우누리
  파일명: starcraft_tip.zip (2,048KB)
  전송방식: Zmodem / Xmodem / Ymodem 선택 -> z
  전송 중...

  [자료실] >> get 333                          <- 천리안

----------------------------------------------------------------------
  파일 업로드
----------------------------------------------------------------------

  하이텔   ul   또는   upload
  나우누리  ul
  천리안   put   또는   ul     <- put은 천리안 고유 표현

  사용 예)
  [자료실] Command: ul
  파일명 입력: game_tip.txt
  설명 입력: 스타크래프트 테란 빌드 오더
  파일 전송 시작...

  [자료실] >> put               <- 천리안 고유 표현

----------------------------------------------------------------------
  파일 목록 보기   --   3사 공통
----------------------------------------------------------------------

  fl   또는   list

  사용 예)
  [자료실] Command: fl
  [자료실] >> list

----------------------------------------------------------------------
  파일 검색
----------------------------------------------------------------------

  하이텔   s [검색어]   또는   search [검색어]
  나우누리  s [검색어]
  천리안   find [검색어]

  사용 예)
  [자료실] Command: s 스타크래프트
  [자료실] 명령어: s 게임공략
  [자료실] >> find 게임


======================================================================
  08. 채팅(대화방) 명령어   [방 만들기, 귓속말 3사 다름!]
======================================================================

go chat 으로 대화방에 들어간 뒤 사용합니다.
방 입장, 나가기, 목록은 동일하지만
새 방 만들기 명령어와 귓속말 명령어가 3사 모두 다릅니다.

----------------------------------------------------------------------
  방번호 입력으로 입장   --   3사 공통
----------------------------------------------------------------------

원하는 번호의 채팅방에 입장합니다.
하이텔 77번 방은 당시 전국구 명소였습니다.

  사용 예)
  [대화방] Command: 77          <- 하이텔 전설의 77번방
  [대화방] 명령어: 1
  [채팅] >> 1

----------------------------------------------------------------------
  /l   또는   /list   --   3사 공통
----------------------------------------------------------------------

현재 열려있는 대화방 목록과 각 방의 인원수를 보여줍니다.

  사용 예)
  [대화방] Command: /l
    1번방: 자유대화 (12명)
    77번방: 그냥대화 (34명)

----------------------------------------------------------------------
  /w   또는   /who   --   3사 공통
----------------------------------------------------------------------

현재 같은 대화방에 있는 사람들의 아이디 목록을 봅니다.

  사용 예)
  [방 안] Command: /w

----------------------------------------------------------------------
  /q   또는   /quit   --   3사 공통
----------------------------------------------------------------------

대화방에서 나옵니다. 대화방 목록 화면으로 돌아갑니다.

  사용 예)
  [방 안] >> /q

----------------------------------------------------------------------
  새 대화방 만들기   [3사 명령어 전부 다름!]
----------------------------------------------------------------------

  하이텔   /create [방이름]
  나우누리  /c [방이름]
  천리안   /open [방이름]

  사용 예)
  [대화방] Command: /create 우리들방    <- 하이텔
  [대화방] 명령어: /c 우리들방          <- 나우누리
  [채팅] >> /open 우리동네방            <- 천리안

----------------------------------------------------------------------
  귓속말   [천리안만 다름!]
----------------------------------------------------------------------

특정 상대에게만 보이는 귓속말을 보냅니다.

  하이텔   say [아이디] [내용]
  나우누리  say [아이디] [내용]     <- 하이텔과 동일
  천리안   whisper [아이디] [내용]  <- 전혀 다른 명령어

  사용 예)
  [방 안] Command: say friend1 지금 몇 번 방이야?    <- 하이텔
  [방 안] 명령어: say friend1 ㅋㅋ 진짜냐?           <- 나우누리
  [방 안] >> whisper friend1 지금 어디야 ㅋ          <- 천리안


======================================================================
  09. 전자우편(메일) 명령어
======================================================================

go mail 로 들어간 뒤 사용합니다.
기본 구조는 3사 모두 같고, 천리안은 긴 명령어 형태를 선호했습니다.

----------------------------------------------------------------------
  l   또는   list   --   3사 공통
----------------------------------------------------------------------

받은 메일 목록을 출력합니다.

  사용 예)
  [메일] Command: l

----------------------------------------------------------------------
  r [번호]   또는   read [번호]   --   3사 공통
----------------------------------------------------------------------

해당 번호의 메일을 읽습니다.

  사용 예)
  [메일] 명령어: r 3
  [메일] >> read 2              <- 천리안은 read 형태 선호

----------------------------------------------------------------------
  s [아이디]   또는   send [아이디]   --   3사 공통
----------------------------------------------------------------------

지정한 아이디에게 메일을 보냅니다.
제목과 내용 입력 후 Ctrl+Z로 저장합니다.

  사용 예)
  [메일] Command: s friend1
  제목: 안녕 잘 지내?
  내용: 오랜만이야! 연락하자.
  ^Z
  메일이 발송되었습니다.

  [메일] >> send friend1        <- 천리안은 send 형태 선호

----------------------------------------------------------------------
  d [번호]   또는   delete [번호]   --   3사 공통
----------------------------------------------------------------------

해당 번호의 메일을 삭제합니다.

  사용 예)
  [메일] 명령어: d 3
  [메일] >> delete 2

----------------------------------------------------------------------
  fw [번호] [아이디]   --   3사 공통
----------------------------------------------------------------------

받은 메일을 다른 사람에게 전달(forward)합니다.

  사용 예)
  [메일] Command: fw 3 friend2  <- 3번 메일을 friend2에게 전달


======================================================================
  10. 회원 조회 / 내 정보 / 환경 설정 / 기타
======================================================================

----------------------------------------------------------------------
  who   또는   u   --   3사 공통
----------------------------------------------------------------------

현재 해당 통신사에 접속 중인 이용자 수와 목록을 보여줍니다.

  사용 예)
  [HiTEL] Command: who

----------------------------------------------------------------------
  finger [아이디]   --   3사 공통
----------------------------------------------------------------------

특정 아이디의 가입 정보, 최근 접속 일시 등을 조회합니다.

  사용 예)
  [나우누리] 명령어: finger friend1

  아이디: friend1
  이름: 홍길동
  가입일: 1995.03.12
  마지막 접속: 1997.07.04 23:11

----------------------------------------------------------------------
  info   --   3사 공통
----------------------------------------------------------------------

내 계정 정보, 총 이용 시간, 이번 달 예상 요금 등을 확인합니다.
분당 요금이 부과되던 시대라 요금 폭탄 방지를 위해 수시로 확인했습니다.

  사용 예)
  [천리안] >> info

  아이디: myid
  가입일: 1994.06.01
  이번달 접속시간: 32시간 14분
  이번달 예상요금: 12,800원

----------------------------------------------------------------------
  set   --   3사 공통
----------------------------------------------------------------------

개인 환경을 설정합니다.
화면 줄 수(보통 24줄), 색상 사용 여부, 자동 로그인 등을 조정합니다.

  사용 예)
  [HiTEL] Command: set
  화면 줄 수 (현재: 24): 24
  색상 사용 여부 (y/n): y

----------------------------------------------------------------------
  cls   --   3사 공통
----------------------------------------------------------------------

화면 전체를 깨끗하게 지웁니다. DOS의 cls와 같은 기능입니다.

  사용 예)
  [천리안] >> cls

----------------------------------------------------------------------
  sos [메시지]   --   하이텔 / 나우누리
----------------------------------------------------------------------

시스템 관리자(시삽)에게 긴급 메시지를 전송합니다.
접속 오류, 요금 이의 등 긴급 상황에 사용했습니다.

  사용 예)
  [HiTEL] Command: sos 접속이 자꾸 끊깁니다 도와주세요
