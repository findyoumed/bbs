================================================================================
   1. 프로젝트 개요 및 아키텍처
================================================================================

  Hanulso BBS는 1990년대 한국 PC통신(나우누리, 하이텔 등)의 사용자 경험을 
  현대적인 Linux 환경(CentOS 등)에서 재현하기 위한 C++ 기반 BBS 서버입니다.

  [ 아키텍처 특징 ]
  - 멀티 프로세스 모델: xinetd가 각 접속을 받아 별도의 바이너리(`main`)를 실행합니다.
  - 모듈화된 바이너리: 로그인 시 기능에 따라 `guest`, `pass`, `main`이 교체(execl)됩니다.
  - 동적 화면 구성: `bbcode_printf`를 사용하여 실시간 접속자 수 등을 화면에 뿌려줍니다.
  - 외부 연동: 운세(LUCK), 날씨(WEATHER) 기능은 외부 웹 서비스를 스크래핑하여 제공합니다.


================================================================================
   2. 사전 준비 및 설치 (Requirements & Install)
================================================================================

  2-1. 필요 패키지 (CentOS 기준)
    - 컴파일러: gcc-c++ (g++)
    - 서비스: xinetd, telnet-server
    - 라이브러리: mysql-devel, zlib-devel, openssl-devel, redhat-lsb-core
    - 보조 도구: lrzsz (ZMODEM), wget, lynx, iconv, nano (또는 vim)

  2-2. 설치 환경 설정
    - 로케일 설정: 반드시 EUC-KR(ko_KR.eucKR) 환경이어야 한글이 깨지지 않습니다.
    - 환경 변수: 프로젝트 루트 경로를 `HANULSO` 환경 변수로 지정해야 합니다.
    - SELinux: 가급적 비활성화(disabled)를 권장합니다.

  2-3. 컴파일 및 실행
    - `src` 디렉토리에서 `make` 명령을 실행하면 `bin/` 폴더에 바이너리들이 생성됩니다.
    - `runbbs` 스크립트를 xinetd 설정(`server_args`)에 등록하여 서버를 구동합니다.


================================================================================
   3. 데이터베이스(MariaDB) 구축 및 스키마 명세
================================================================================

  서버 실행 전 MariaDB에 `hanulso.cfg`에서 지정한 이름의 DB와 테이블을 생성해야 합니다.

  [ 주요 테이블 스키마 ]
  - member (회원): USER_ID, PASSWORD, NICK_NAME, BIRTHDAY, EMAIL, SEX, LEVEL, 
                   REGISTRATION_DATETIME, LASTLOGIN_DATETIME 등.
  - memo (쪽지): SENDER_USER_ID, RECIPIENT_USER_ID, TITLE, CONTENT, DATE_TIME 등.
  - attachment (첨부파일): FAMILY_TABLE, FAMILY_ID, FILENAME, ORIGINAL_FILENAME 등.
  - 게시판 테이블 (가변 명칭): NO, FAMILY(쓰레드), ORDERBY, STEP, USER_ID, TITLE, CONTENT 등.


================================================================================
   4. 서버 환경 설정 (hanulso.cfg & hanulso.mnu)
================================================================================

  4-1. hanulso.cfg (XML 형식, EUC-KR)
    - <database>: 호스트, 유저, 암호, DB명 설정.
    - <mailserver>: SMTP 서버 및 인증 정보 (비번 초기화 메일 전송용).
    - <sysop>: 관리자 아이디 목록.
    - <article>: 한 화면 최대 게시물 라수 (`show_max_line`).
    - <level>: 레벨별 명칭 및 권한 설정.

  4-2. hanulso.mnu (메뉴 정의 파일)
    트리 구조의 XML 형식을 통해 게시판과 하위 메뉴를 정의합니다.
    - <item type="menu">: 서브 메뉴 구성 (text속성으로 화면 텍스트 파일 지정).
    - <item type="board">: 게시판 구성 (id로 DB 테이블 매핑).
    - <item type="chatt">: 대화방 연동.
    - <item type="weather">: 날씨 정보 기능 연동.


================================================================================
   5. 프로젝트 디렉토리 및 주요 파일 구조
================================================================================

  - [src/]   : 모든 C++ 소스 코드 및 Makefile 위치.
  - [bin/]   : 컴파일된 바이너리 (`main`, `guest`, `pass`, `sysop`, `weather` 등).
  - [txt/]   : 터미널 화면용 정적 텍스트 파일 (.txt) 및 도움말.
    - [txt/door/]: 접속 시 무작위로 출력될 대문 화면들.
  - [file/]  : 업로드된 첨부파일이 저장되는 공간.
  - [tmp/]   : 실시간 접속 정보(.tty), 세션, 임시 로그 보관.
  - [chatt/] : 개설된 대화방 정보(.room) 보관.
  - runbbs   : 텔넷 세션 시작 시 실행되는 게이트웨이 스크립트.
  - vi.rc    : BBS 내에서 글쓰기 시 사용되는 vi 에디터 설정 (블루스크린 스타일).


================================================================================
   6. 터미널 인터페이스 및 화면 제어 (BBCode & ANSI)
================================================================================

  Hanulso BBS는 표준 ANSI 이스케이프 코드와 자체 BBCode를 혼합하여 화면을 제어합니다.

  [ 지원하는 BBCode 태그 ]
  - [hostname]       : 게시판 시스템 이름 출력.
  - [nummembers]     : 현재 가입된 전체 회원 수.
  - [numconns]       : 현재 접속 중인 동시 사용자 수.
  - [numarticles]    : 시스템 전체 게시글 수.
  - [todaynumarticles]: 오늘 올라온 새 글 수.
  - #PAGE            : 긴 텍스트 출력 중 "계속하려면 엔터를 치세요" 구분을 생성.

  [ 화면 스타일 ]
  - `vi.rc`를 통해 파란색 배경에 흰색 글씨(Blue Screen)를 기본값으로 제공하여 
    전통적인 PC통신 느낌을 부여합니다.


================================================================================
   7. 터미널(Telnet) 사용법 및 명령어 (Command Guide)
================================================================================

  7-1. 로그인 및 회원가입
    - ID란에 `guest` 입력 시 신규 가입 절차(`bin/guest`)가 시작됩니다.
      (ID 중복 체크, 비밀번호 강도 체크, 이메일 인증 절차 포함)
    - ID란에 `pass` 입력 시 분실한 비밀번호를 이메일로 발급(`bin/pass`)받을 수 있습니다.
    - 가입 중 단계별 취소는 `/x` 명령어를 사용합니다.

  7-2. 게시판 및 첨부파일 명령어
    - [번호] : 게시글 읽기. (읽기 중 A:다음글, N:이전글, P:목록으로)
    - W / RE : 글쓰기 / 답글 쓰기.
    - DD / ED: 내 글의 삭제 및 수정.
    - DN [번호]: 첨부파일 다운로드 (ZMODEM 사용).
    - UP [번호]: 첨부파일 업로드 (글 작성 시 사용).
    - LA / NA / PA: 첨부파일 목록 보기 및 페이지 이동.
    - OK     : 게시글 추천.
    - LS [번호]: 특정 번호부터 목록 보기.

  7-3. 대화방(채팅) 명령어
    - O      : 새로운 대화방을 개설합니다. (포트 6000번대부터 자동 할당)
    - [번호] : 대화방 입장. (비밀방의 경우 비밀번호 확인)
    - [대화 중 명령어]
      - /say [ID] [내용]: 특정 사용자에게 귓속말 보내기.
      - /list : 대화방 내 참여자 목록 확인.
      - /quit : 내가 만든 방인 경우 방을 닫고 퇴장.
      - /bye  : 대화방만 퇴장하고 로비로 복귀.

  7-4. 특수 기능 (Entertainment)
    - BIO  : 이름과 생년월일을 입력하여 오늘의 바이오리듬 확인.
    - MBTI : 문답식 성격 유형 검사 수행.
    - LUCK : 성별, 생년월일, 양력/음력 정보를 입력하여 오늘의 운세 확인 (웹 연동).
    - WEATHER: 지역별 날씨 정보를 실시간으로 조회 (웹 연동).


================================================================================
   8. 운영자(SYSOP) 관리 기능 및 도구
================================================================================

  `hanulso.cfg`에 등록된 관리자 계정은 `SYS` 혹은 `SYSOP` 명령을 사용할 수 있습니다.
  별도의 `bin/sysop` 바이너리가 실행되며 다음 기능을 제공합니다.

  1. 회원 검색: 아이디로 닉네임 찾기, 혹은 그 반대.
  2. 회원 정보 수정: 강제 비밀번호 변경, 사용자 레벨(`LEVEL`) 조정 등.
  3. 회원 삭제: 불량 이용자 계정을 데이터베이스에서 영구 삭제.
  4. 게시판 관리: 특정 게시물의 강제 삭제 및 권한 관리.


================================================================================
   9. 문제 해결 및 기술 팁 (Troubleshooting)
================================================================================

  - 한글 깨짐 현상: 클라이언트(PuTTY, 데이타맨 등)의 인코딩이 반드시 'EUC-KR' 이어야 합니다.
  - ZMODEM 수신 불가: 서버에 `lrzsz` 패키지가 설치되어 있는지 확인하십시오.
  - DB 연결 실패: `hanulso.cfg` 내의 MariaDB 접속 정보와 MySQL 서비스 상태를 점검하십시오.
  - 날씨/운세 오류: 서버가 외부 네트워킹(http)이 가능해야 하며 `lynx`, `wget`, `jq` 명령어가
    정상 작동해야 합니다.
