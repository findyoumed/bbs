📡01. 접속 및 로그인CONNECT & LOGIN

모뎀으로 통신사 서버에 전화를 걸어 접속한 뒤 아이디와 암호를 입력합니다. 하이텔과 나우누리는 같은 망(01410)을 공유했고 천리안은 독자 망(01420)을 사용했습니다. 접속 후 나타나는 프롬프트 모양이 3사 모두 다릅니다.

▶ 하이텔
ATDT 01410
모뎀 전화 → 하이텔 선택
▶ 나우누리
ATDT 01410
동일 번호 → 나우누리 선택
▶ 천리안
ATDT 01420
천리안 전용 독자 번호
▼ 하이텔 접속 후 프롬프트 HiTEL 2.0 / 반갑습니다. 하이텔입니다. ID: myid PW: ****** [HiTEL] Command: ▼ 나우누리 접속 후 프롬프트 나 우 누 리 에 오신것을 환영합니다 나우누리 아이디: myid 암호: ****** [나우누리] 명령어: ▼ 천리안 접속 후 프롬프트 천 리 안 PC-Serve / 천리안 서비스에 오신것을 환영합니다. 아이디: myid 암호: ****** [천리안] >>
하이텔은 "Command:", 나우누리는 "명령어:" (한글 최초), 천리안은 ">>" 기호. 프롬프트 생김새가 통신사를 구분하는 가장 쉬운 방법이었습니다.
🧭02. 이동 명령어 — GO / P / M / Q / BYENAVIGATION
go [키워드]3사 공통

가장 핵심적인 명령어. 어느 화면에서든 go 뒤에 키워드를 입력하면 해당 서비스나 게시판으로 바로 이동합니다. 키워드는 통신사마다 다른 것이 있습니다.

▶ 3사 공통 go 키워드
go humor유머란 (3사 동일)
go chat대화방 (3사 동일)
go mail전자우편 (3사 동일)
go bluehouse청와대 신문고 (3사 동일)
▶ 하이텔 주요 go 키워드
go plaza자유/시사 게시판
go humor유머란
go pgfPC게임 동호회
go anc애니메이션 동호회
go jubu주부 동호회
go barun바른통신 동호회
go summer여름 이벤트
go chat / mail / bluehouse공통
▶ 나우누리 주요 go 키워드
go plaza자유/시사 게시판

p  /  prev3사 공통

[프라자] Command: p ← 하이텔 [유머란] 명령어: p ← 나우누리 [word] >> p ← 천리안
m  /  main3사 공통

어느 화면에서든 메인(첫) 화면으로 한 번에 이동합니다.

[자료실] 명령어: m → 나우누리 메인 화면으로 이동
q  /  quit3사 공통

현재 서비스를 종료하거나 로그아웃합니다.

bye  /  logout3사 공통

통신사 서버에서 완전히 로그아웃하고 모뎀 연결을 끊습니다. 분당 요금이 부과되던 시대라 bye를 치는 순간이 중요했습니다.

[HiTEL] Command: bye → 접속 종료. 모뎀 끊김. 요금 부과 중단.
당시에는 분당 요금이 부과됐습니다. 읽을 글을 메모장에 복사해 두고 빨리 bye를 치는 게 생활 요령이었습니다.
숫자 입력 (1, 2, 3...)3사 공통

메인 메뉴나 서비스 목록 화면에서 번호를 직접 입력해 해당 항목을 선택합니다.

[HiTEL] Command: 1 → 메뉴 1번 항목 선택
📋03. 게시판 — 목록 보기LIST

[프라자] Command: l ← 최신 글 목록 [프라자] Command: l 500 ← 500번부터 목록 [유머란] 명령어: l 50 ← 50번부터 목록 [word] >> list ← 천리안, list도 가능

[프라자] Command: r 1024 [유머란] 명령어: r 5432 [word] >> r 888 또는 [word] >> read 888

[글 읽는 중] 명령어: b
f [번호]3사 공통

특정 번호 글 위치로 바로 이동합니다. 오래된 글을 빠르게 찾을 때 사용했습니다.

[프라자] Command: f 2000 → 2000번 글 위치로 바로 이동
new  /  nw3사 공통

지난번 접속 이후 새로 올라온 글만 골라서 보여줍니다. 자주 방문하는 게시판에서 빠르게 새 글만 확인할 때 사용했습니다.

[word] >> new → 마지막 접속 이후 새 글만 출력
✍️05. 게시판 — 글쓰기 / 답글 / 수정 / 삭제WRITE / REPLY / EDIT / DELETE
w  /  write3사 공통

새 글을 작성합니다. 제목과 내용을 입력한 후 Ctrl+Z (또는 /end)로 저장합니다.

[프라자] Command: w 제목: 오늘 있었던 웃긴 일 내용 입력 (Ctrl+Z 로 저장, Ctrl+C 로 취소): 오늘 버스에서 정말 황당한 일이... ^Z → 글이 저장되었습니다. (1025번)
re [번호]  /  a [번호]  /  answer [번호]3사 공통

특정 글에 답글(리플)을 답니다. re, a, answer 모두 사용 가능했습니다.

[유머란] 명령어: re 5432 → 5432번 글에 답글 작성 [word] >> re 888 → 천리안도 re 동일
e [번호]  /  edit [번호]3사 공통

자신이 작성한 글을 수정합니다. 다른 사람 글은 수정 불가.

[프라자] Command: e 1024 → 1024번 글 수정 (본인 글만 가능)
d [번호]  /  delete [번호]3사 공통

자신의 글을 삭제합니다. 삭제 전 확인 메시지가 나옵니다.

[유머란] 명령어: d 5432 삭제하시겠습니까? (y/n): y → 글이 삭제되었습니다.
h  /  help3사 공통

현재 화면에서 사용 가능한 명령어 목록과 도움말을 출력합니다.

[word] >> help → 사용 가능한 명령어 목록 출력
🔍06. 게시판 — 검색 【3사 명령어 다름!】SEARCH

제목 검색과 내용 검색 명령어가 하이텔·나우누리와 천리안이 완전히 다릅니다.

gl [검색어]하이텔 나우누리  |  subj [검색어]천리안

게시글 제목으로 검색합니다. 하이텔·나우누리는 gl (get list의 약자), 천리안은 subj를 씁니다.

▶ 하이텔 / 나우누리

▶ 천리안
subj 대통령
제목에 "대통령" 포함된 글 검색
[프라자] Command: gl 선거 [유머란] 명령어: gl 군대 [word] >> subj 선거
ga [검색어]하이텔 나우누리  |  body [검색어]천리안

게시글 본문 내용까지 포함해서 검색합니다. 제목 검색보다 시간이 더 걸렸습니다. 하이텔·나우누리는 ga, 천리안은 body를 씁니다.

▶ 하이텔 / 나우누리
ga 대통령
본문 포함 전체 검색
▶ 천리안
body 대통령
본문 전체 검색
[프라자] Command: ga 선거 [word] >> body 선거
💾07. 자료실 — 파일 다운로드 / 업로드 / 검색 【3사 다름!】FILE TRANSFER

파일 다운로드 명령어가 3사 모두 다릅니다. 특히 나우누리의 tr은 전설적인 명령어로 유저 유입의 핵심 원인이 됐습니다.

dl [번호]하이텔    tr [번호]나우누리 ★전설    get [번호]천리안

자료실에서 파일을 다운로드합니다. 나우누리의 tr(transfer)은 속도와 안정성으로 유명해졌고, 이 명령어 하나 때문에 하이텔·천리안 유저들이 나우누리로 대거 이동했습니다.

▶ 하이텔
dl 1234
1234번 파일 다운로드
▶ 나우누리 (전설의 tr)
tr 1234
1234번 파일 다운로드
▶ 천리안
get 1234
1234번 파일 다운로드
[자료실] 명령어: tr 1234 파일명: starcraft_tip.zip (2,048KB) 전송방식: Zmodem / Xmodem / Ymodem 선택 → z ▓▓▓▓▓▓▓▓▓░░░░░░░ 58% 전송 중...
전송 방식은 Zmodem이 가장 빠르고 안정적이었습니다. 도중에 끊겨도 Zmodem은 이어받기가 됐습니다.
ul하이텔 나우누리  |  put  /  ul천리안

자료실에 파일을 올립니다. 천리안은 put도 사용 가능했습니다.

[자료실] Command: ul 파일명 입력: game_tip.txt 설명 입력: 스타크래프트 테란 빌드 오더 → 파일 전송 시작... [자료실] >> put ← 천리안 고유 표현
fl  /  list3사 공통

자료실의 파일 목록을 출력합니다.

[자료실] Command: fl [자료실] >> list
s [검색어]하이텔 나우누리  |  find [검색어]천리안

자료실에서 파일명이나 설명으로 파일을 검색합니다.

💬08. 채팅(대화방) 명령어 【방 만들기·귓속말 3사 다름】CHAT

go chat 으로 대화방에 들어간 뒤 사용합니다. 방 입장·나가기·목록은 동일하지만 새 방 만들기 명령어와 귓속말 명령어가 3사 모두 다릅니다.

방번호 입력3사 공통

[대화방] Command: 77 ← 하이텔 전설의 77번방 [대화방] 명령어: 1 [채팅] >> 1

[대화방] Command: /l 1번방: 자유대화 (12명) 77번방: 그냥대화 (34명)
/w  /  /who3사 공통

현재 같은 대화방에 있는 사람들의 아이디 목록을 봅니다.

[방 안] 명령어: /w → 현재 방 참여자 목록 출력

say [아이디] [내용]하이텔 나우누리  |  whisper [아이디] [내용]천리안 천리안 다름!

특정 상대에게만 보이는 귓속말을 보냅니다. 하이텔·나우누리는 say, 천리안은 whisper를 씁니다.

⚙️10. 회원 조회 / 내 정보 / 환경 설정 / 기타SETTINGS & INFO

set3사 공통

[HiTEL] Command: set 화면 줄 수 (현재: 24): 24 색상 사용 여부 (y/n): y
