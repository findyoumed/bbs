이 문서는 프로젝트의 과거 기록, 릴리즈 내역, 상세 분석 보고서 및 레거시 설명서를 보관하는 공간입니다.

---

## 1. 과거 설명서 (레거시)

### 1-1. 상세 사용자 설명서 (2026-03-23 기준)
이 설명서는 초기 웹 기반 BBS의 사용자 인터페이스와 명령어를 정의한 자료입니다.

- **접속과 기본 이동**:
  - `go [메뉴명]`: 서비스 바로가기
  - `p` / `m`: 이전 화면
  - `t` / `top`: 메인 메뉴
  - `q` / `quit`: 종료
- **게시판 명령어**:
  - `l`: 목록 보기
  - `Enter` / `f`: 다음 페이지
  - `b`: 이전 페이지
  - `[번호]`: 글 읽기
  - `lt [단어]`: 제목/본문 검색
  - `w`: 글 쓰기
- **채팅 명령어**:
  - `/l`: 대화방 목록
  - `/w`: 대기실 인원 확인
  - `/q`: 대화방 퇴장
  - `o`: 방 개설

### 1-2. 개발자 설명서 (2026-03-23 기준)
- **화면 크기**: 640px 고정 (80칸 * 8픽셀)
- **글꼴**: DungGeunMo 16px
- **데이터 구조**: FAMILY, ORDERBY, STEP 조합을 통한 답글 정렬
- **주요 테이블**: `member`, `attachment`, `memo`, `chat_rooms`
