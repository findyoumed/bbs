## 프로젝트 구조
- `/public/js/app.js`: 메인 애플리케이션 로직 (화면 전환, API 연동)
- `/public/js/core/commandRouter.js`: 명령어 라우팅 및 한글 오타 매핑
- `/public/js/core/postScreens.js`: 게시판 목록 및 본문 렌더링
- `/public/js/core/signupFlow.js`: 회원가입 단계별 로직
- `/server.js`: Node.js Express 서버 진입점

## 핵심 환경
- **Port**: 3000
- **Database**: Supabase (Backend/Auth)
- **UI**: 01410 Monochrome Terminal Style

AI 에이전트 및 Ralph Loop 시스템이 파일을 정확히 찾을 수 있도록 프로젝트 구조를 이곳에 명시합니다.
